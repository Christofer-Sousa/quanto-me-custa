# 💸 Quanto Me Custa?

> Descubra quanto da sua vida uma compra realmente custa.

O **Quanto Me Custa?** é uma calculadora simples que transforma o preço de um produto em **tempo de trabalho**.

Em vez de mostrar apenas:

> 💰 R$ 5.000

o projeto mostra uma perspectiva diferente:

> ⏱️ Quantas horas da sua vida você precisa trabalhar para comprar isso?

Além disso, a aplicação apresenta equivalências em dias, semanas e salários, junto com um veredito baseado no percentual que a compra representa do salário.

---

## ✨ Funcionalidades

- 💰 Cálculo do valor da hora de trabalho
- ⏱️ Cálculo das horas necessárias para comprar um produto
- 📅 Conversão para dias de trabalho
- 🗓️ Conversão para semanas de trabalho
- 💼 Cálculo de quantos salários a compra representa
- 📊 Percentual do salário comprometido
- ⚖️ Sistema de veredito financeiro
- 🎨 Resultado visual com cores diferentes para cada veredito
- ✅ Validação dos dados informados
- 📱 Interface responsiva

---

## 🧠 Como funciona?

O usuário informa:

- Salário mensal
- Horas trabalhadas por dia
- Dias trabalhados por semana
- Nome do produto
- Preço do produto

A aplicação utiliza esses dados para calcular o **custo real da compra em tempo de trabalho**.
